# go-renovatebot

Go structs generated from [Renovate](https://github.com/renovatebot/renovate)'s published
`renovate-schema.json`, kept in sync with upstream releases.

Every tracked Renovate release gets its own git tag matching that release's version (with the
`v` prefix Go module tooling requires), so you can pin to the exact structs for the Renovate
version you run:

```sh
go get github.com/maxcraig112/go-renovatebot@v44.116.0
```

```go
import "github.com/maxcraig112/go-renovatebot"

var cfg renovatebot.Config
if err := json.Unmarshal(data, &cfg); err != nil {
    // ...
}
```

`renovatebot.Config` is the root `renovate.json` config type; every other type referenced by the
schema is generated alongside it.

## Keeping up to date

An hourly workflow checks for new Renovate releases and publishes a tagged commit for each one
automatically.

Structs also exist for every past release that published a schema (roughly Renovate v34 onward),
generated by a one-off backfill; expect a very large number of tags, one per Renovate release
with a published schema.
